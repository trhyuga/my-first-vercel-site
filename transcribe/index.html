🎵 音声ファイル MP3 変換

音声ファイルを、MP3 へ。

WAV などの大きな音声ファイルをドロップすると、端末内で MP3 に変換します。サーバーには一切送信されません。

🔒 音声はこの端末から一切送信されません。 すべてブラウザ内で処理します。
🎵

タップして音声を選択 / ドラッグ&ドロップ

WAV 推奨 (MP3 / M4A / OGG / FLAC 等も可)
PC の Chrome / Edge は変換ボタンを押すと保存ダイアログが出て、ファイル名と保存場所を指定できます。
iPhone / iPad は変換後に「📤 共有して保存」をタップ → 「ファイルに保存」で保存先を選べます。

✅ MP3 変換完了

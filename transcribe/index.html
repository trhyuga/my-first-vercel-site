🎵 音声ファイル変換 & 文字起こし

音声ファイルを、MP3 と文字 へ。

WAV などの大きな音声ファイルをドロップすると、端末内で MP3 に変換、または文字起こしできます。サーバーには一切送信されません。

🔒 音声はこの端末から一切送信されません。 すべてブラウザ内で処理します。
📝 文字起こし機能は実験中 (β)。Whisper を Web Worker で隔離して 90 秒ごとに処理 (内部で 30 秒 × 5 秒オーバーラップ stride)。tiny は日本語幻覚が多いので base を推奨、PC なら small が最も自然です。捏造された括弧ラベル ((知事) など) は自動で除去します。
🎵

タップして音声を選択 / ドラッグ&ドロップ

WAV 推奨 (MP3 / M4A / OGG / FLAC 等も可)
MP3 変換: PC の Chrome / Edge は変換前に保存ダイアログ、iPhone は「📤 共有して保存」で保存先を選べます。
文字起こし: 初回のみモデル (tiny ≒ 40MB / base ≒ 75MB) を取得します。WebGPU 対応 (Chrome / Edge) で高速。

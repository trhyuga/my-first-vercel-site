🎬 MOV→MP4 変換

MOV を、MP4 へ。

iPhone やカメラの MOV 動画をドロップすると、端末内で MP4 に変換します。サーバーには一切送信されません。

🔒 動画はこの端末から一切送信されません。 すべてブラウザ内で処理します。
🎬

タップして動画を選択 / ドラッグ&ドロップ

MOV 推奨 (M4V / AVI / MKV / WebM 等も可)
おまかせ: iPhone / カメラの MOV (H.264・HEVC) はそのままコピーするので一瞬で終わり、画質も劣化しません。コピーできない形式は自動で再エンコードに切り替えます。
再エンコード: どんな形式でも H.264 の MP4 にし直します。互換性は最高ですが、動画の長さに応じて時間がかかります。
PC の Chrome / Edge は保存ボタンでファイル名・保存場所を指定できます。iPhone / iPad は「📤 共有して保存」→「ファイルに保存」で保存先を選べます。

✅ MP4 変換完了

すべて端末内処理・動画のサーバー送信なし
変換エンジン: ffmpeg.wasm ／ ひゅうがのTR-Labo
